# IEEE-WEBDEV-CHALLENGE
This is my submission for the IEEE CS PESU Web Development Recruitments Challenge. The challenge was to design and deploy a production-ready website for Confluence hackathon. I wanted to give the website my own twist, so I went with an retro arcade and  Windows XP-inspired aesthetic. Tech stack: I used Astro for SSG with plain HTML, CSS and JavaScript, built with Node.js npm and deployed it on Vercel. I vibe coded most of it through Antigravity.
