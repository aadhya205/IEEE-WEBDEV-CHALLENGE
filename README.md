# aadhya-confluence-2026 — Confluence 2025 Portal


Created as a submission for the IEEE CS PESU Web Development Recruitments Challenge, this project pairs its retro arcade aesthetic with Windows XP-inspired elements and was developed with Antigravity assistance.

- 🌐 **Live Website**: [https://aadhya-confluence-2026.vercel.app](https://aadhya-confluence-2026.vercel.app)
- 📊 **Vercel Project**: [aadhya-confluence-2026](https://vercel.com/aadhya8/aadhya-confluence-2026)

---

## 🚀 Website Sections & Features

1. **Top Taskbar**: Clean navigation bar with IEEE CS logo, active section tracking, and link to the [Google Slides Finalist Pitch Deck](https://docs.google.com/presentation/d/1fI5FFfKuqRj5BTz8OGMAptzq1CdKxlpp/edit#slide=id.p1).
2. **Hero Title Screen**: 3D title with verified event statistics (₹70,000 Prizes, 24 Hours, BE Block 13F, 40 Squads).
3. **8 AI Problem Themes**: Expandable track prompts covering Sustainability, Mobility, Healthcare, Smart Cities, Education, Entertainment, Disaster Relief, and Generative AI.
4. **24-Hour Quest Roadmap**: Glowing cyber-energy trail covering all phases from check-in to final awards.
5. **Top 40 Finalists Leaderboard**: Interactive high-score board with real-time squad name and rank search.
6. **Sponsors & Ecosystem**: Verified partner logos and collaboration credits.
7. **Frequently Asked Questions**: Categorized accordion covering logistics, eligibility, fees, and rules.
8. **Contact & Venue**: Verified coordinator contacts (Tejas Kumar, Neha S) and embedded PES University RR Campus address.

## 💻 Tech Stack

- **Framework**: [Astro](https://astro.build/) (Static Site Generation / SSG)
- **Styling**: Pure Vanilla CSS (`src/styles/global.css`)
- **Typography**: Google Fonts (`Josefin Sans`, `Nunito`, `VT323`)
- **Hosting**: [Vercel](https://vercel.com/)

---

## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
# Server runs at http://localhost:4321

# 3. Build for production
npm run build

# 4. Deploy to Vercel
npx vercel deploy --prod
```
